# 🚀 Mi Portafolio Personal | Full Stack & Data Analytics

Bienvenido a mi repositorio del portafolio profesional. Aquí presento una selección de mis proyectos más destacados en desarrollo web **Full Stack** y **Business Intelligence**, mostrando arquitecturas _Serverless_, integraciones de pagos, rendimiento extremo y dashboards analíticos para la toma de decisiones.

## 🌟 Proyectos Destacados

### 🛒 1. MagicNests — Full Stack E-commerce

> **Tecnologías:** Nuxt 4, Vue 3, Tailwind CSS, Pinia, Stripe API, SQLite, Cloudflare Pages.

Plataforma de comercio electrónico de alta velocidad y rendimiento construida sobre arquitectura _Serverless Edge_.

- ⚡ **Performance:** Tiempos de respuesta Edge inferiores a 100ms y puntuación de 100/100 en Lighthouse/SEO.
- 💳 **Pasarela de Pagos:** Integración segura con Stripe Checkout API y Webhooks en tiempo real con Nitro.
- 📦 **Estado Reactivo:** Gestión global del carrito y sesión mediante Pinia.
- 🔗 **Demo:** [magicnests.com](https://magicnests.com)

---

### 📊 2. TechNova Solutions S.L. — Business Intelligence Dashboard

> **Tecnologías:** Power BI, DAX, Power Query, Python.

Caso de estudio de analítica ejecutiva _End-to-End_ diseñado para simular un proceso de consultoría estratégica real.

- 🔄 **ETL & Data Prep:** Ingesta y limpieza de datos sintéticos generados en Python a través de Power Query.
- 📐 **Modelado de Datos:** Arquitectura de modelo dimensional en estrella (_Star Schema_).
- 📈 **Métricas Avanzadas:** Cálculos de ventas, márgenes, cohortes de clientes y análisis comparativo histórico utilizando DAX.
